## 📌 Projects

### ✅ Task 1: Hangman Game

**Description:**

A simple text-based word-guessing game built using Python. The player must guess a randomly selected word one letter at a time.

**Features:**
- Randomly selects a word from five predefined words.
- Allows the player to guess one letter at a time.
- Limits incorrect guesses to six.
- Displays correctly guessed letters.
- Notifies the player when they win or lose.

**Technologies Used:**
- Python
- Random module
- While loops
- If-else statements
- Strings and lists

**How to Run:**

```bash
python task1-hangman/hangman.py
```

---

### ✅ Task 2: Stock Portfolio Tracker

**Description:**

A simple Python application that calculates the total value of stock investments using predefined stock prices and user-entered quantities.

**Features:**
- Displays available stock symbols and example prices.
- Accepts stock symbols and quantities from the user.
- Calculates the value of each stock holding.
- Displays the total portfolio value.
- Optionally saves the portfolio summary to a CSV file.

**Technologies Used:**
- Python
- Dictionaries
- User input and output
- Loops and conditional statements
- Basic arithmetic
- CSV file handling

**How to Run:**

```bash
python task2-stock-portfolio/stock_tracker.py
```
